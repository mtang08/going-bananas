## 2. Obtainability classes

- **V verified**: the official path is documented, *and* repo code already ingests the field (author-run; not re-run on this Mac).
- **D derivable**: computable from documented FIT/JSON fields (FIT Profile legality only). Whether the FR265 actually populates them is gated on **GATE-G2**.
- **M manual-input**: only obtainable through user entry in the app.
- **X unsupported**: no authorized field path established, or no valid derivation for the intended use.

The brief's check, "Garmin Connect UI ≠ obtainable data", was applied. Training Status, VO2max, lactate threshold, and HRV Status are visible in the Connect UI, but no Personal API or ordinary-FIT field was established for them (feasibility matrix rows `vendor_*`, `garmin_training_status_load`; FR265 section on HRV Status). The overnight HRV value the repo stores (`lastNightAvg`) is *not* HRV Status. Activity FIT HRV (RR intervals) is not overnight HRV.
