## Verified knowledge and decision inputs (single shared contract)

`decision_inputs.py` owns frozen `VerifiedKnowledge(digest:str,selection:tuple[dict,...],selected_records:tuple[dict,...],policy_ids:frozenset[str],recipe_ids:frozenset[str],evidence_ids:frozenset[str])` and `KnowledgeResolver = Callable[[tuple[dict,...]],VerifiedKnowledge]`. Selection entries are `{path,sections:[heading...]}` or `{path,record_ids:[id...]}`; order retained. Selected records are `{path,record_id,content:<full canonical record>}` sorted path/id. Digest hashes the verified manifest plus selected excerpt bytes and selected records. ID sets cover the verified whole package. No unverified caller IDs substitute for this object.

TASK060 exports `verify_selection(selection)->dict` with exactly those six fields. TASK062/063/064 construct VerifiedKnowledge(**verify_selection(selection)); resolver callbacks use that same expression. 061 never imports later snapshot or parallel knowledge modules. Snapshot stores selection in kb_routes and selected_records in payload.snapshot_meta.knowledge.selected_records from this object. On submit/acceptance resolver verifies current bytes for the saved selection, not a newly selected route; changed content changes digest/fingerprint.

`collect_decision_inputs(session,operation:str,as_of:date,*,now:datetime,kb:VerifiedKnowledge)->dict` returns source_versions,source_fingerprint,safety_guard. Exact source vector schemas§6.4, canonical JSON SHA256 sorted compact keys, preserve meaningful array order, reject NaN. Canonical vector is `{source_versions:<collector projection>,knowledge:{digest,selection,selected_records}}`; operational generated_at/calculated_at/proposal rows/source revision noise excluded. `decision_input_fingerprint` same args returns its source_fingerprint. Collector also reads original app.models.Checkin (schema1) rows with now−72h <= observed_at <= now, ordered observed_at,id. Its source_versions.legacy_checkins list contains `{schema_version:1,id,version,observed_at,activity_id,symptoms,change,gait,feeling,effort,severity_numeric:null}`; no note/idempotency_key and no converted numeric symptom/illness/fatigue facts. Original row remains source authority; do not double count imported mapping copies. safety_guard.legacy_safety_active = any(gait=='affected' or symptoms=='severe' or (symptoms=='moderate' and change=='worse')). This flag is ORed with numeric v2 guard, never overwritten by a newer mild v2 check-in. Older-than72h/future legacy rows excluded. This preserves categorical safety at cutover without inventing severity scores. Read-only/no commit; no circular imports. Static fixture planning/remaining_mvp/contracts/coach-fingerprint.json provides canonical encoded vector+expected hash;061 tests load it, alter selected content to the supplied second hash, and verify proposal insertion/derived writes do not change collected source vector.

1. Constants: `OPERATIONS` (6 keys, `coaching_contract.md` §2); `RECIPE_IDS = {f"REC{n:03d}" for n in 1..10}`; `QUALITY_RECIPES = {"REC003","REC004","REC005","REC006","REC008","REC009"}`; `LONG_RECIPE = "REC002"`; `BLOCK_OPS = {"review_training_block","handle_goal_or_race_change"}`; `OFF_CYCLE_OPS = {"review_rolling_plan","review_training_block","handle_goal_or_race_change"}`; `ANCHOR_KINDS` (8, `schemas.md` §2.5); `ANCHOR_UNITS = {"bpm","mps","s","m"}`; `ANCHOR_UNIT={"hr_aerobic_upper":"bpm","hr_threshold_lower":"bpm","speed_aerobic_upper":"mps","speed_threshold_lower":"mps","performance_5k":"s","performance_1mile":"s","performance_3min":"m","performance_20_30min":"mps"}`; `PROTOCOLS` (8, `metrics.md` §3.1); `ANCHOR_CONFIDENCE = {"high","moderate","low","insufficient"}`. `safety_active(guard: dict | None) -> bool` = True if `guard` is not a dict (fail closed), else `guard["gait_change_yes"] or (guard["max_symptom_severity"] is not None and guard["max_symptom_severity"] >= 6.5) or guard["illness_present"] or guard["clinical_restriction_active"] or guard["legacy_safety_active"]`. Helper `is_quality_slot(kind, recipe_id, placeholder) = kind == "run" and (recipe_id in QUALITY_RECIPES or placeholder)`. `scope(op, today)` = `(today, today+3)` for `proceed_or_modify_today`, else `(today, today+13)`. `derive_certainty(d, today)` = `"committed"` if `d <= today+6` else `"provisional"`.
2. Pydantic v2 models, all `model_config = ConfigDict(extra="forbid")`:
   - `Confidence`: `decision, evidence, data: Literal["high","moderate","low"]`.
   - `Target`: `modality: Literal["speed","hr","effort"]`, `low: float|None=None`, `high: float|None=None`, `effort_cue: str|None = Field(None, max_length=200)`.
   - `RepeatBlock`: `type: Literal["repeat"]`, `count: int (ge=2)`, `steps: list[StructureStep] (min_length=1)`; nesting forbidden. `StructureStep`: `type: Literal["warmup","work","recovery","cooldown"]`, `duration_type: Literal["time","distance"]`, `duration_value: float (gt=0)`, `target: Target|None=None`.
   - `SessionFields` (all optional, default None; "set" = `model_fields_set`): `local_date: date`, `slot: int (ge=0)`, `kind: Literal["run","strength","cross","rest","mobility"]`, `recipe_id: str`, `custom: bool`, `placeholder: bool`, `locked: bool`, `intent: str (max 200)`, `planned_duration_s: int (gt=0)`, `planned_distance_m: int (gt=0)`, `structure: list[StructureStep|RepeatBlock]`, `strength_slot_id: UUID`, `notes: str`.
   - `Change`: `change_id: str` pattern `^c[1-9][0-9]{0,9}$`, `op: Literal["add","modify","move","delete"]`, `session_uid: UUID|None=None`, `after: SessionFields|None=None`, `reason: str (min 1)`, `material_flags: list[Literal["off_cycle_run","strength_move"]] = []`. `model_validator(mode="after")` raising `ValueError`: add → `session_uid` None and `after` has `local_date`, `kind`, `intent` set; modify → `session_uid` set, `after` set and non-empty, `local_date` not set; move → `session_uid` set, `after` fields set ⊆ {`local_date`,`slot`} and includes `local_date`; delete → `session_uid` set, `after` None.
   - `BlockVersionFields`: `status: Literal[draft|active|consolidating|completed|replaced|ended]`, `objective: str`, `rationale: str`, `maintained_qualities: list[str]`, `non_goals: list[str]`, `eligible_recipe_ids: list[str]`, `progression_dimension: Literal[duration|frequency|long_run|quality_volume|intensity|none]`, `constraints: list[BlockConstraint{kind: str, text: str}]`, `start_date: date`, `review_date: date`, `completion_indicators: list[str]`, `early_review_triggers: list[str]`, `objective_status: Literal[unresolved|partially_achieved|achieved|not_achieved]`. `BlockChange`: `decision: Literal[start|continue|extend|consolidate|transition|replace|end]`, `block_uid: UUID|None`, `version_fields: BlockVersionFields`.
   - `AnchorChange`: `kind: str`, `value_low: float`, `value_high: float|None`, `unit: str`, `protocol: str`, `confidence: str`, `calibrated_at: AwareDatetime`, `source_activity_id: UUID|None`, `conditions: str|None`, `supersedes_key: str|None (max 40)` (strings so V14 owns enum errors).
   - `ProposalDoc`: `schema_version: Literal["coach_proposal.v1"]`, `operation: Literal[6 ops]`, `snapshot_id: UUID`, `base_calendar_version: int (ge=0)`, `base_block_version_id: UUID|None`, `summary: str (1..2000)`, `rationale: str (1..8000)`, `confidence: Confidence`, `changes: list[Change] (max 50)`, `preserved: list[UUID] = []`, `block_change: BlockChange|None = None`, `anchor_changes: list[AnchorChange] = []`, `evidence_ids, policy_ids, recipe_ids: list[str]`, `observations_used: list[str] = []`, `follow_up: str|None`, `escalation: Literal[6 ops]|None`, `skill_version: Literal["running-coach.v1"]`. `recipe_id` stays `str` (V6 owns it).
3. Dataclasses (frozen): `ValidationIssue(code, path, message)` + `to_json()`; `HeadSession(session_uid, revision, local_date, slot, kind, recipe_id, custom, placeholder, locked, legacy_unstructured, intent, certainty, planned_duration_s, planned_distance_m, structure, strength_slot_id, notes)`; `ActiveBlock(block_uid, version_id, version, eligible_recipe_ids: tuple[str,...])`; `SnapshotRef(id, operation, as_of, generated_at, source_fingerprint, kb_routes, kb_digest, safety_guard: dict | None)`; `ValidationContext(now, today, tz, snapshot: SnapshotRef|None, head_version: int, head_sessions: dict[UUID, HeadSession], active_block: ActiveBlock|None, cycle_anchor: date|None, current_safety_guard:dict|None,current_source_fingerprint:str,current_kb_digest:str, kb: VerifiedKnowledge)`; `ValidationResult(status: Literal["pending","invalid","stale"], doc: ProposalDoc|None, issues: list[ValidationIssue])`.
4. `parse_document(raw) -> tuple[ProposalDoc|None, list[ValidationIssue]]`: on `pydantic.ValidationError` return one issue per `errors()` entry: code `V1.schema`, path `".".join(str(x) for x in err["loc"])`, message `err["msg"]`.
5. `validate_parsed(doc, ctx) -> ValidationResult`, in this order:
   - **V2** (`snapshot_id`/`operation` paths): `ctx.snapshot is None` → `V2.snapshot_not_found`; operation differs → `V2.operation_mismatch` (path `operation`); `ctx.now - generated_at > 24 h` → `V2.snapshot_expired`. Any V2 issue → return `invalid` now.
   - **V3**: `base_calendar_version != ctx.head_version` → `V3.stale_base` path `base_calendar_version`; `base_block_version_id != (active.version_id or None)` → `V3.stale_base` path `base_block_version_id`. If bases match, snapshot.source_fingerprint≠ctx.current_source_fingerprint or snapshot.kb_digest≠ctx.current_kb_digest → V3.stale_sources path snapshot_id. Any V3 issue returns stale immediately.
   - Run **V4–V15** below, collect all issues; any → `invalid`, else `pending`.
6. Resulting state: start from `head_sessions` (key `str(uid)`), apply changes in order (skip a change whose `session_uid` is unknown): add → key `new:<change_id>` with `after` fields (`custom` default False, `slot` 0); modify → overlay set fields; move → overlay `local_date`/`slot`; delete → remove. "Head value" of a field = `HeadSession` value; "resulting value" = after-set value if set else head value. Monday of `d` = `d - timedelta(d.weekday())`.
7. Rules (path `changes.{i}` unless stated; one issue per offending item):
   - **V4**: repeated `change_id` → `V4.duplicate_change_id` (`changes.{i}.change_id`); unknown `session_uid` → `V4.unknown_session` (`changes.{i}.session_uid`); uid in an earlier change → `V4.session_in_multiple_changes` (`changes.{i}.session_uid`); `preserved[j]` not in head → `V4.unknown_preserved` (`preserved.{j}`).
   - **V5**: dates checked = add: after date; modify/delete: head date; move: head and after dates. Outside `scope()` → `V5.out_of_scope`.
   - **V6**: add with kind `run`, or modify whose resulting kind is `run` and whose set fields include any of `kind`, `recipe_id`, `custom`, `structure` (a modify touching only other fields of the bootstrap quality placeholder is allowed, D18): resulting `recipe_id` None and not (resulting `custom` and non-empty resulting `structure`) → `V6.recipe_required` (`changes.{i}.after`); recipe not in `RECIPE_IDS` → `V6.unknown_recipe` (`changes.{i}.after.recipe_id`); eligible set = `doc.block_change.version_fields.eligible_recipe_ids` if `block_change` else active block's set else none; recipe not in it → `V6.recipe_not_eligible` (`changes.{i}.after.recipe_id`).
   - **V7**: each date in scope with > 1 resulting `run` → `V7.multiple_runs_per_day`, path `changes`, message names the date.
   - **V8**: changes producing a run: add kind run; move of a head run; modify turning a non-run into a run. If `opportunity(date, ctx.cycle_anchor) is None` and not (`"off_cycle_run"` in flags and op in `OFF_CYCLE_OPS`) → `V8.off_cycle`.
   - **V9**: move of a head strength session: daily op → `V9.daily_strength_move`; else no `"strength_move"` flag → `V9.strength_move_flag`. Daily op adding/deleting a strength session or modifying kind to/from strength → `V9.daily_strength_change`. Each Monday `w` with `w >= scope start` and `w+6 <= scope end` with < 2 resulting strength sessions → `V9.strength_count`, path `changes`.
   - **V10**: each Mon–Sun week overlapping scope with > 1 resulting run whose `recipe_id == "REC002"` → `V10.multiple_long`, path `changes`. Move of a head quality slot (`is_quality_slot`) into a different week whose resulting quality-slot count exceeds its head count → `V10.quality_pileup`.
   - **V11**: each `policy_ids[j]`/`recipe_ids[j]`/`evidence_ids[j]` not in `ctx.kb` set → `V11.unknown_kb_id` (`policy_ids.{j}` etc.).
   - **V12** (only if `safety_active(ctx.current_safety_guard)`): for changes whose resulting date ∈ `[today, today+3]`: add kind run; move of a head run from outside that window; modify turning non-run into run; modify with `planned_duration_s` set and (head value None or new > head); add/modify setting `recipe_id` ∈ `QUALITY_RECIPES` → `V12.safety_guard`.
   - **V13** (if `block_change`): op not in `BLOCK_OPS` → `V13.block_change_not_allowed` (`block_change`); else `V13.block_change_invalid` for: `start` with an active block (`block_change.decision`); `start` with `block_uid` set (`block_change.block_uid`); non-start with no active block (`block_change.decision`); non-start with `block_uid != active.block_uid` (`block_change.block_uid`); `review_date <= start_date` (`block_change.version_fields.review_date`); eligible id not in `RECIPE_IDS` (`block_change.version_fields.eligible_recipe_ids.{j}`).
   - **V14**: non-empty `anchor_changes` with op ≠ `recalibrate_intensity` → `V14.anchor_change_not_allowed` (`anchor_changes`). Per item `j`, `V14.anchor_invalid` at `anchor_changes.{j}.<field>`: kind ∉ `ANCHOR_KINDS`; unit ∉ `ANCHOR_UNITS` or unit != ANCHOR_UNIT[kind] (field `unit`); protocol; confidence; `value_high` not None and `value_low > value_high` (field `value_high`); duplicate `anchor_key(item, ctx.tz)` (field `kind`). `anchor_key(a, tz) = f"{a.kind}-{a.calibrated_at.astimezone(tz).date().isoformat()}"`.
   - **V15**: op `select_quality_session`: change op ≠ modify, or head session not a quality slot → `V15.not_quality_slot`. Op `recalibrate_intensity`: change op ≠ modify or set fields ⊄ {`intent`,`structure`,`notes`} → `V15.recalibrate_change_not_allowed`.

After ANY source change (including anchor-only/block-only), mark_pending_stale except this proposal. No-op decisions leave others fresh.
