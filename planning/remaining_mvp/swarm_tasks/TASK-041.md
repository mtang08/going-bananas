## Objective and observable end state
`<Calendar unit="mi"/>` lists today…today+13 ("Next 14 days") and today−7…today−1 ("Past 7 days") from `GET /calendar`, lets the user edit, move, add, and delete future sessions (each save = one `POST /calendar/edits` → new version), record an outcome for a past session, view any earlier version read-only, and undo the latest eligible changed version (`POST /calendar/rollback`). Example: moving session `s1` from 2026-11-12 to 2026-11-13 with reason "trip" sends `{expected_head:2, reason:'trip', edits:[{op:'move', session_uid:'s1', fields:{local_date:'2026-11-13'}}]}` and then shows "Saved as version 3."
