## Objective and observable end state
Per run activity and per rolling window, one result holding separate `hr` and `speed` 3-zone distributions with explicit valid/unknown time. Example: 3,600 timer-on seconds with HR easy 2,700 s, moderate 450 s, high 150 s, 120 s invalid HR and one 180 s record gap → `hr.easy_s=2700.0, moderate_s=450.0, high_s=150.0, valid_s=3300.0, unknown_s=300.0, eligible_timer_s=3600.0, coverage=0.917`, status `available`.

## Implementation procedure
1. Constants: `METRIC_ID="intensity_time_distribution"`, `WINDOW_DAYS=(7, 14, 28, 56, 84)`, `DEPENDS_ON=()`, `MODALITIES={"hr": ("hr_aerobic_upper", "hr_threshold_lower"), "speed": ("speed_aerobic_upper", "speed_threshold_lower")}`, `CONFIG={"max_record_gap_s": 10, "zones": ["easy", "moderate", "high"], "zone_rule": "lower_inclusive", "hr_valid_bpm": [30, 230], "speed_valid_mps": [0, 10], "coverage_good": 0.9, "coverage_limited": 0.7}`.
2. `@dataclass(frozen=True) class StreamIn: t_s: list[int]; hr_bpm: list[float | None]; speed_mps: list[float | None]; timer_on: list[tuple[int, int]]`.
3. `zone(v, aerobic_upper, threshold_lower) -> str` (rule above). `sample_valid(modality, v) -> bool`: `v is not None` and `30 <= v <= 230` (hr) / `0 <= v <= 10` (speed).
4. `distribution(modality, stream, aerobic_upper, threshold_lower) -> dict`: loop `integrate_timer_on(stream.t_s, stream.timer_on, 10)`; `eligible += ov`; value `v = series[i]` only when i is not None; if `i is None or not known or not sample_valid` → `unknown += ov`; else `zone_s[zone(v)] += ov`. Return `{"easy_s", "moderate_s", "high_s", "valid_s", "unclassified_s": 0.0, "unknown_s", "eligible_timer_s", "coverage" (valid/eligible, None if eligible == 0), "fraction_valid" ({easy, moderate, high} ÷ valid, None if valid == 0), "fraction_timer" (÷ eligible, None if eligible == 0)}` — fractions from unrounded seconds, then rounded.
5. `modality_outcome(modality, stream: StreamIn | None, anchors: dict[str, ActiveAnchor], local_date: date, session_timer_s: float | None) -> dict` with keys `{"status", "reason_codes", "quality_status", "flags", "anchors_used", ...distribution keys, "confidence"}`. Checks in order (first hit returns with all distribution numbers `None`): stream None → `missing` `["NO_STREAM"]`; either kind absent or `confidence == "insufficient"` → `not_assessable` `["ANCHOR_MISSING"]`; `aerobic.value_low >= threshold.value_low` → `invalid` `["ANCHOR_CONFIG_ERROR"]`; every element of the modality series is None → `missing` `["HR_NOT_RECORDED"]`/`["SPEED_NOT_RECORDED"]`; `eligible_timer_s == 0` → `missing` `["NO_TIMER_ON_DATA"]`. Otherwise quality = `coverage_label(valid, eligible)`; status `available` if good else `partial` with `["LOW_COVERAGE"]`. `confidence` = lower of the two anchor confidences (order high > moderate > low), `None` when anchors unusable. Flags in order: `LOW_CONFIDENCE_ANCHOR` (confidence low), `ANCHOR_REVIEW_DUE` (`local_date > review_after` of either), `TIMER_MISMATCH` (`session_timer_s` not None and `abs(eligible − session_timer_s) > max(1,.01*session_timer_s)`); TIMER_MISMATCH => modality not_assessable with null distribution and retained diagnostic timer totals per E33. `anchors_used` = the two `ActiveAnchor`s from the third check onward, else `[]`.
6. `activity_outcome(stream, anchors, local_date, session_timer_s) -> dict` → `{"status", "quality_status", "value", "reason_codes", "quality_flags", "anchor_keys", "anchors_used"}`: `value = {"hr": hr_dict, "speed": speed_dict, "session_timer_s": session_timer_s}` where each modality dict holds `status, reason_codes, confidence` + distribution keys (drop `flags`, `anchors_used`, `quality_status`). Row status: both available → `available`; else any modality available/partial → `partial`; else any not_assessable → `not_assessable`; else any invalid → `invalid`; else `missing`. Row reasons = sorted union of modality reasons; row flags = sorted union of modality flags; quality = lower of computed modality qualities (good > limited > insufficient), None if none; `anchor_keys` = sorted keys of all anchors used.
7. `window_outcome(items: list[dict | None]) -> dict` — one item per run in the window: the stored per-activity row as `{"status", "value", "anchor_set_hash", "anchor_keys"}` or None (no row). Per modality m: counted = items whose `value[m]["status"]` ∈ {available, partial}; sum the six second fields over counted; `coverage`, fractions as step 4; modality `status`: no runs → available zeros only with complete activity coverage; otherwise missing/null with SYNC_COVERAGE_INCOMPLETE; counted == 0 → `not_assessable` with `["NO_ACTIVITY_COUNTED"]` if any item's modality status is not_assessable, else `missing` `["NO_ACTIVITY_COUNTED"]`; otherwise `available` if every item counted and available, else `partial` with reasons `ACTIVITIES_NOT_COUNTED` (counted < total) then `PARTIAL_ACTIVITY_COVERAGE` (any counted partial); `confidence=None`; plus `activities_total`, `activities_counted`, `activities_without_result` (None items). `value = {"hr": ..., "speed": ..., "anchor_set_hashes": sorted distinct non-None}`; row status/reasons/quality combine as step 6 (quality per modality = `coverage_label(valid, eligible)` when eligible > 0); `anchor_keys` = sorted union.
8. `compute`: activity key → `Activity` + `ActivityStream` (`session.get(ActivityStream, activity_id)`; `timer_on` → `[tuple(x) for x in row.timer_on]`), run from `load_runs(session, d, d+1)`, `anchors = active_anchors(session, run.local_date)` → `activity_outcome`; `unit="s"`, `anchor_set_hash = anchor_set_hash(anchors_used)` if any else None, `source_refs={"activity_ids": [id], "anchor_keys": [...]}`. Window key → runs via `load_runs`, rows via `latest_results(session, METRIC_ID, METHOD_VERSION, [str(id) ...])`, `window_outcome`; `anchor_set_hash=None`; `source_refs={"activity_ids": [...]}`.
