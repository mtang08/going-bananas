## Objective and observable end state
Two registered metrics computing from stored activities. Example: three runs on local dates 2026-11-10/12/14 with timer 2100/2700/4200 s and 5800/7400/11200 m give `w7:2026-11-15` → `timer_duration_s=9000.0, distance_m=24400.0, run_count=3, status=available`. A run of 5040 s / 13500 m with prior-30-day max 4500 s / 12200 m and a 7-day total of 12600 s / 33000 m gives `duration_ratio_to_recent_max=1.12, distance_ratio_to_recent_max=1.107, weekly_share_duration=0.4, weekly_share_distance=0.409`.

## Implementation procedure
1. `volume.py`: `METRIC_ID="run_volume_frequency"`, `WINDOW_DAYS=(7, 14, 28, 56, 84)`, `DEPENDS_ON=()`, `CONFIG={"window_days": [7, 14, 28, 56, 84], "sports": ["running", "trail_running", "treadmill_running"], "duration_field": "timer_s", "local_day_rule": "start_at_in_profile_tz"}`.
2. `parse_window_key(key: str) -> tuple[int, date]` (regex `^w(\d+):(\d{4}-\d{2}-\d{2})$`, N must be in `WINDOW_DAYS`) — export it; TASK-021/023 do not import it (they repeat the same regex).
3. `totals(runs: list[RunFact], start: date, end_excl: date) -> dict`: select `start <= r.local_date < end_excl`; return `{"start_date", "end_date" (end_excl − 1 day), "run_count", "timer_duration_s" (round(sum of non-None timer_s), 1)), "distance_m" (same for distance), "runs_missing_timer", "runs_missing_distance"}`. Sums over zero runs are 0.0 only with complete coverage; all-unknown measurements for present runs are None.
4. `volume_outcome(runs, as_of: date, days: int, coverage_complete: bool, previous_coverage_complete:bool) -> dict` returning `{"status", "quality_status", "value", "reason_codes", "quality_flags", "activity_ids"}`: `start = as_of − (days−1)`; `cur = totals(runs, start, as_of+1)`; `prev = totals(runs, start−days, start)`; reasons `TIMER_MISSING` if `cur.runs_missing_timer`, then `DISTANCE_MISSING` if `cur.runs_missing_distance`; `status = partial` if reasons or incomplete coverage else `available`; empty incomplete window missing/null; flags `("SYNC_COVERAGE_INCOMPLETE",)` if not `coverage_complete`; `quality_status = good` if status available and no flags else `limited`; `value = {**cur, "previous": {**prev,"coverage_complete":previous_coverage_complete}}`; previous all-unknown/empty rules applied independently; `activity_ids` = ids in the current window.
5. `volume.compute`: parse key; `runs = load_runs(session, start−days, as_of+1)`; `coverage_complete = activities_coverage_complete(session, start, as_of+1)`; previous_coverage_complete = activities_coverage_complete(session,start−days,start); one `MetricResult(unit=None, source_refs={"activity_ids": [...]})`.
6. `long_run.py`: `METRIC_ID="long_run_exposure"`, `WINDOW_DAYS=(7, 14, 28, 56, 84)`, `DEPENDS_ON=("symptom_response_timeline",)`, `CONFIG={"precedence": ["plan_link", "manual", "long_rule"], "long_recipe": "REC002", "rule": "long_rule.v1", "rule_multiplier": 1.33, "rule_lookback_days": 28, "rule_min_prior_runs": 4, "comparator_lookback_days": 30, "break_lookback_days": 14, "weekly_window_days": 7, "weekly_includes_current": True}`.
7. `classify(run, prior_28: list[RunFact], plan_linked: bool, plan_recipe: str | None) -> tuple[str, str, str]` = (classification ∈ `long|not_long|unknown`, source ∈ `plan_link|manual|long_rule`, confidence ∈ `high|low`): plan_linked → (`long` iff recipe == `REC002` else `not_long`, `plan_link`, `high`); elif `run.workout_label is not None` → (`long` iff label == `long` else `not_long`, `manual`, `high`); else `timers` = non-None `timer_s` of `prior_28`; if `run.timer_s is None` or `len(timers) < 4` → (`unknown`, `long_rule`, `low`); else `long` iff `run.timer_s >= 1.33 * statistics.median(timers)`, source `long_rule`, `low`.
8. `exposure_outcome(run, history: list[RunFact], plan_linked, plan_recipe, coverage_complete_week: bool, delayed_symptom_status: str, linked_checkin_ids: list[str]) -> dict` (same keys as step 4). `history` contains every run with local date in `[d−30, d]` (d = run.local_date), including `run`. Define `others = [h for h in history if h.activity_id != run.activity_id]`; `prior_28 = [h for h in others if h.start_at < run.start_at and h.local_date >= d−28]`; `prior_30` same with `d−30`; `week = [h for h in history if d−6 <= h.local_date <= d]` (includes run and later same-day runs).
   - Base value: `{"activity_id", "local_date", "timer_s", "distance_m", "classification", "classification_source", "classification_confidence", "delayed_symptom_status", "linked_checkin_ids"}`.
   - `not_long` → `not_applicable`, reasons `("NOT_LONG_RUN",)`, quality None. `unknown` → `not_assessable`, reasons `CLASSIFICATION_UNKNOWN` then `INSUFFICIENT_HISTORY` (if < 4 prior timers) then `TIMER_MISSING` (if run.timer_s None); quality None.
   - `long` → add `prior_max_timer_s`, `prior_max_distance_m` (max over non-None of `prior_30`, else None; incomplete input adds PARTIAL_COMPARATOR), `duration_ratio_to_recent_max`, `distance_ratio_to_recent_max` (current / prior max, None if either None or max == 0), `week_timer_s`, `week_distance_m` (known subtotals in `week`, None if all unknown, flag PARTIAL_WEEK if any missing), `weekly_share_duration`, `weekly_share_distance` (current / week total, None if current None or total == 0), `comparator_window={"start_date": d−30, "end_date": d}`, `weekly_window={"start_date": d−6, "end_date": d}`. Reasons in order: `INSUFFICIENT_HISTORY` if `prior_30` empty, `TIMER_MISSING`, `DISTANCE_MISSING`. Status `available` if all four ratios/shares are non-None else `partial`. Flags in order: `RETURN_FROM_BREAK` if no `others` run has local date in `[d−14, d−1]`; `SURFACE_NOT_COMPARABLE` if the run supplying `prior_max_timer_s` or `prior_max_distance_m` (first in `prior_30` order on ties) has `sport != run.sport`; `SYNC_COVERAGE_INCOMPLETE` if not `coverage_complete_week`; `LOW_CONFIDENCE_CLASSIFICATION` if source `long_rule`. Quality `good` if status available and no flags, else `limited`.
9. `delayed_status(checkins: list[tuple[str, list[float]]]) -> str` — input `(kind, severities)` per linked check-in: no `delayed_followup` check-in → `unknown`; any delayed one with a severity > 0 → `reported`; else `none_reported`.
10. `window_outcome(entries: list[dict]) -> dict` — `entries` = per-activity `value` dicts (only rows whose value is not None), in run order: `long = [e for e in entries if e["classification"] == "long"]`; status `available`; quality None; `value = {"long_run_count": len(long), "latest": long[-1] if long else None}`.
11. `long_run.compute`: activity key → load `Activity`, `d` = `start_at` in `athlete_tz`; `history = load_runs(session, d−30, d+1)`; find run (else ACTIVITY_EXCLUDED/`[]` per common rules). Plan link (private `_plan_link(session, activity_id) -> tuple[bool, str | None]`): `SessionCompletion` with that `activity_id`; none → `(False, None)`; `head = AppState.calendar_head_version`; newest `CalendarSessionRevision` for its `session_uid` with `calendar_version_number <= head`; none, `deleted`, or `kind != 'run'` → `(False, None)`; else `(True, recipe_id)`. Linked check-ins: shared symptoms.linked_activity_for_checkin, ordered by observed_at/id, including inferred links only with known end. `coverage_complete_week = activities_coverage_complete(session, d−6, d+1)`. Row `unit=None`, `source_refs={"activity_ids": [run + prior_30 ids], "session_uid": str | None, "checkin_ids": [...]}`. Window key → `load_runs` for the window, `latest_results(session, METRIC_ID, METHOD_VERSION, ids)`, `window_outcome`, `source_refs={"activity_ids": [...]}`.
