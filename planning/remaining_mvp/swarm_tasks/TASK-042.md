## Objective and observable end state
`<Activity activityId="a1" unit="mi" onCheckin={fn}/>` loads `GET /activities/a1/execution` and shows, for a structured workout, one row per rep with planned vs actual values; for a watch/plan structure mismatch, the planned and watch step lists side by side with the reason; for a run without decoded FIT, summary values only with an explicit "not assessable" notice. Example: rep 1 of the fixture (800 m in 205 s) shows pace "6:52 /mi".
